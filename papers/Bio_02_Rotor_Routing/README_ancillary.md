# Ancillary bundle for "The sandpile group as a coordinate system on genome reconstructions" (`rotor_assembly.tex`, Bio 2)

`rotor_assembly.py` reproduces every computational claim: 8 checks, 8 passing, about 5 s.
Requires `sympy`, reached through `pgl3_building.py` in the `Paper 10` folder of the ANCFT
series (exact integer Smith normal form with transforms, Bareiss determinant); the path is
resolved relative to this file, so keep the folders as siblings. Run
`python rotor_assembly.py`. The archived output is `rotor_assembly_output.txt`.

**Data.** `phix174_NC_001422.1.txt` (5386 bp, one uppercase A/C/G/T string) is read from
beside the script; no network access is needed.

Checks, keyed as in the paper's battery table:

| key | content | arithmetic |
|-----|---------|-----------|
| (A) | rotor-routing action of K(G) on spanning arborescences of six assembly graphs: well defined, by permutations; the group generated by one chip at each non-sink vertex has order \|K\| and a single orbit, and the action is free. \|K\| up to 27 | exact |
| (B) | the BEST bijection implemented explicitly: (arborescence toward the sink, a cyclic order of the non-tree out-arcs at every vertex) -> arc-rooted Eulerian circuit, and it is a bijection onto the brute-force enumeration on four graphs (288, 576, 144, 8 circuits) | exact |
| (M) | one chip = one move: adding a chip at a k-mer and re-reading the circuit gives another sequence with the same k-mer spectrum; the moves are printed (6 positions changed in the example; a chip that is trivial in K changes nothing) | exact |
| (U) | exact uniform sampling of K(G) via Smith-form coordinates (uniform residues mod the invariant factors, mapped back by the row transform), followed by rotor-routing from a base arborescence; 2700 draws on a 27-element group, all 27 arborescences hit, chi^2 = 31.2 on 26 df, p = 0.22 | sampled |
| (W) | Wilson's loop-erased-random-walk sampler on the same graph (chi^2 = 22.3, p = 0.67): the classical route to a uniform arborescence. The group adds what Wilson does not give: the chip word taking one sample to another (here 3 chips) | sampled |
| (J) | **one chip is not one transposition**: on the compacted phiX174 graph at k = 11 (10 branch vertices) the nine chip generators re-thread 6, 5, 3, 2, 4, 2, 3, 1, 0 junctions respectively — a single re-threading in 1/9 cases; the rotor walk changes the tree arc at every branch vertex it passes. On the small example: 2, 3, 1 | exact |
| (F) | phiX174 at k = 12: K = Z/2, so the 12-mer spectrum leaves exactly ONE global binary choice. Both reconstructions are exhibited (5386 bp each, both with the phage's 12-mer spectrum) and shown to be the reference A X B U A Z B Y vs A X B Y A Z B U for two INTERLEAVED repeated 12-mers A = CTTCTGCCGTTT (positions 457, 3205) and B = CGTCAAGGACTG (264, 2760), with X = 3217..263 (2433 nt, wrapping), U = 276..456 (181), Z = 469..2759 (2291), Y = 2772..3204 (433): the Z/2 of the interleaving theorem of Bio 1 v2, in a real genome. One chip performs the exchange. By the GenBank feature table U spans the C/D gene junction and Y the G/H (spike) junction, so the alternative is a misassembly, not a viable isomer. At k = 11, K = Z/2 + Z/66: 132 global classes | exact |
| (N) | **local constraints are not cosets**: the set of arborescences with a prescribed tree arc at a branch vertex (what a long read fixes), transported to K(G) through the torsor, is a coset of a subgroup in only 5/7, 6/8, 9/9, 6/9 cases on the four graphs of check (A); all cosets only on the single-repeat graph AABBAABBAABB (K = (Z/3)^2). So long-read constraints cannot be combined by linear algebra in K(G) | exact |

Conventions. Sink = vertex 0 of the (compacted) graph; rotors are out-arc indices in
sorted order and a chip rotates the rotor at its current vertex forward by one before
moving (the "rotate then move" convention of Holroyd et al.). BEST circuits are read with
the tree arc LAST at every non-sink vertex and start at the sink with its smallest out-arc,
matching the arc-rooted brute force. Compacted arcs carry the concatenated (k+1)-mer
labels so a circuit on the compacted graph can be spelled back into a full-length
sequence.

Two traps, recorded because both bit us. (1) A single repeat of multiplicity 2 creates NO
circular ambiguity — W X W Y and W Y W X are rotations of one another — so a Z/2 at k = L
always means two interleaved repeats, never one; the first version of check (F) asserted
the single-repeat picture and failed. (2) `act()` must return the canonical tuple form
even when the chip configuration is empty, or arborescence lookups break.
