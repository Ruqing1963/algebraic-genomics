# lib/

`pgl3_building.py` is the shared support module from Paper 10 of the parent series,
*Algorithmic non-commutative class field theory, X: A₂ complexes, higher simplicial Laplacians,
and the fate of the trace obstruction*. The Bio 1–11 verification scripts import its Laplacian
and Smith-normal-form utilities through their `_sib("lib")` helper.

It is copied here unchanged, so that the repository runs on its own. The original is
`Paper 10/pgl3_building.py` in the series root.
